# 产出（不入 git）

> **按需生成的临时快照**：讲解 HTML、跨业务说明稿、交接清单、回溯报告……

## 铁律

1. **不长期维护、不入 git、可随时清空。** 知识库更新后重生即可。
2. **每个产物头部注明**：用途 / 生成日期 / 来源文件。
3. 发现产出内容与知识库不一致 → **改知识库，不改产出**。

## 为什么不维护它

一旦开始手工维护产出，就出现了第二份事实来源，知识库必然腐坏。合并版 / 完整版也属按需产出——生成到这里，**不放进 `../业务认知/`**。

## 怎么生成

在库根目录跟 AI 说明要什么、给谁看、什么场景。它会按 `../AGENTS.md` 的**场景包 A** 读取知识库并落到这里。

**默认是纯文字产出。** 素材不入 git，使用者手上没有图；确需配图时由维护者从 `../原始素材/` 现取。
