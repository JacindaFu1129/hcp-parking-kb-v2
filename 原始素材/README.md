## 目录约定

```
原始素材/
├── v2.5_BS/                 设计画板，按 版本_平台 分目录
├── v3.0_BS/
├── v3.1_BS/  v3.1_CS/
├── v3.1.1_BS/  v3.1.1_CS/
├── v3.2_BS/

│   └── 停车诱导配置/

```

- 画板文件名**保留需求号**（OR/DR/DDR/DOR…），便于与需求单对应。
- 平台后缀必填：**BS** = Web 管理端，**CS** = 客户端/岗亭。
