## 字段约定

每条变更条目固定带这几个标签，其中两个是找设计稿的关键：

| 字段 | 取值 | 作用 |
|---|---|---|
| **类型** | 🆕新增功能 / ✏️优化 / 🔁整合重构 / 🌐定制转基线 | 分类与统计 |
| **范围** | **整页** / **区块** / **单控件** | ★ 决定这张稿子是不是完整的 |
| 平台 | BS / CS | 同一业务两端各有一版稿 |
| 页面 | 菜单路径 | 供 `../页面地图.md` 按页面反查 |
| 业务主题 | 对应 `../业务认知/` 文件 | 供按主题回溯 |

> ⚠ **范围 = 区块 / 单控件的条目，其设计稿只画了改动部分。** 想看完整页面，去 `../页面地图.md` 查该页面有没有整页基线稿。
